# 决策日志：中文审核产物

## D-001：面向人的内容默认使用简体中文

- 状态：已接受
- 决策：Sovei 生成的 Feature Markdown 模板、12 个阶段的提示契约、工作流 CLI 状态和项目初始化/扫描引导尽量使用简体中文。
- 理由：中文是当前项目的主要审查语言，直接决定需求、范围、任务和验证产物能否被高效人工审核。
- 拒绝方案：只翻译本次 `specs/` 文件。这样下一次运行仍会重新生成英文模板，不能进入产品版本。

## D-002：兼容性标识保持不变

- 状态：已接受
- 决策：命令名、阶段 ID、文件名、JSON/YAML 字段、事件类型、代码符号和第三方专有名词保持现有英文；说明文字、标题和提示语使用简体中文。
- 理由：这些标识是机器契约，翻译会破坏脚本、事件回放和外部适配器兼容性。

## D-003：更新两套模板来源

- 状态：已接受
- 决策：同时更新引擎运行时生成模板与 `harness/templates/sovei/` 静态模板，避免两个来源语言不一致。

## 未决事项

无。国际化配置和多语言切换不在本版本范围内；当前默认语言直接设为简体中文。
