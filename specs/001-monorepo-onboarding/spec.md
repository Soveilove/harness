# 功能规格：Monorepo 初始化扫描与中文审核产物

## 问题

Sovei 自扫描时，仓库根目录没有 `package.json` 会导致技术栈和入口为空；同时引擎生成的 Feature 模板、阶段提示和 CLI 引导大量使用英文，不便于当前项目人工审查。

## 用户可见行为

1. `sovei project onboard` 能发现扫描深度内的 `packages/*/package.json`，聚合技术栈并输出带包路径的入口。
2. 根项目名称和描述仍由根清单或项目声明决定，子包不能取代根身份。
3. 自动生成知识始终为 candidate，不自动晋级 stable，也不自动激活治理红线。
4. 新生成的 Feature Markdown 模板、阶段 Prompt Contract、工作流状态提示、项目初始化和扫描引导默认使用简体中文。
5. 阶段名、命令、文件名、JSON/YAML 字段、事件类型和源码符号保持英文兼容标识。
6. `harness/templates/sovei/` 静态模板与引擎运行时模板保持同一语言策略。

## 验收场景

- AC-1：根目录无清单但存在 TypeScript 子包时，扫描结果包含子包、TypeScript 与限定路径入口。
- AC-2：根清单和子包同时存在时，根项目身份不被子包覆盖。
- AC-3：多个包检测出不同技术栈值时，结果确定性聚合，不按扫描顺序静默取第一个。
- AC-4：普通单包项目的检测、候选知识和幂等刷新行为不回归。
- AC-5：新建任一阶段产物时，模板说明与 Prompt Contract 为简体中文，不再生成英文 `Generated by`、`Authority Rules`、`Input/Action/Output/Stop` 占位骨架。
- AC-6：工作流 CLI 和项目 CLI 的说明性输出为简体中文，同时原命令和机器字段可继续使用。
- AC-7：静态 Markdown 模板使用简体中文标题和字段提示；YAML 状态模板字段保持不变。

## 边界

- 隐式包发现仍限定为扫描深度内的直接 `packages/*`。
- 不引入多语言配置系统；本版本默认简体中文。
- 不翻译机器契约、第三方专有名词或代码标识符。

## 明确排除

- 任意 workspace glob 解析和包依赖图。
- 自动知识晋级或红线激活。
- 翻译历史归档产物。
- 对源代码变量、类型、命令与存储 schema 做中文化重命名。
