# 量化系统知识技能

## 核心概念

### 策略回测框架
- 回测须防止未来函数（look-ahead bias）：任何时点只能用截至该时点的数据。
- 事件驱动回测（vectorbt / backtrader / 自研）逐 bar 推进，撮合模拟成交价、滑点、手续费。
- 向量化回测（pandas/numpy）速度快但简化撮合，仅用于策略初筛。
- 样本内外划分：训练集 / 验证集 / 样本外，避免过拟合；用 walk-forward 滚动验证。
- 关键指标：年化收益、夏普、最大回撤、Calmar、换手率、胜率、盈亏比。

### 数据管道
- 行情数据按频率分层存储：tick / 分钟 / 日线，冷热分层（热数据 SSD/内存，冷数据 Parquet/列存）。
- 复权处理（前复权/后复权）须与策略逻辑一致，跨品种对齐时间轴。
- 数据校验：缺失、异常跳变、停牌处理，建立数据质量监控。
- 增量更新与历史重算分离，避免全量重算。

### 风控系统
- 事前：仓位限制、单标的暴露、行业/风格暴露、杠杆上限。
- 事中：实时盯市、回撤阈值熔断、单笔下单金额/数量限制。
- 事后：绩效归因、风险因子暴露分析（Barra 风格因子）。
- VaR / 压力测试 / 极端情景回测，区分正常市场与尾部风险。

### 订单管理
- 拆单算法（TWAP / VWAP / POV / 冰山）降低冲击成本。
- 订单状态机：新建 → 已发 → 部分成交 → 全成交/撤单，状态变更须幂等。
- 母子单管理，子单失败重试与超时回收。
- 与交易所对接注意流控、断线重连、心跳与序号校验。

### 市场数据接入
- 行情源区分 Level1 / Level2，延迟与成本权衡。
- 订阅式（WebSocket）与拉取式（REST）混用，实时行情订阅 + 历史数据接口。
- 时间戳对齐：交易所时间 vs 本地时间，以交易所为准，记录本地接收延迟。
- 多市场时区处理统一到 UTC 存储，展示层转换。

### 因子挖掘
- 因子定义清晰：计算窗口、成分股、加权方式、去极值/标准化/中性化处理。
- 因子评价：IC/IR、分层回测、单调性、换手、衰减分析。
- 避免数据挖掘偏差：因子库过大时用多重检验校正，关注样本外稳定性。
- 因子合成：等权、回归加权、ICIR 加权，注意共线性。

### 机器学习应用
- 标签构造：未来 N 期收益分类/回归，避免标签泄露。
- 特征工程须在时点 t 仅用历史信息，时序交叉验证（forward chaining）。
- 模型选型：树模型（XGBoost/LightGBM）基线，深度学习（LSTM/Transformer）用于序列特征。
- 过拟合防控：早停、正则、样本外验证、实盘小资金灰度验证。
- 解释性：SHAP / 因子重要性，避免黑盒策略直接上实盘。
