# 代码地图索引

本目录回答“代码在哪里、真实链路如何运行、修改前需要检查什么”。地图是导航证据，不替代当前源码、产品 Spec 或运行时验证。

## 地图列表

| 地图 | 覆盖范围 | 适用场景 |
|---|---|---|
| [recent-work-code-map.md](recent-work-code-map.md) | 近期高频入口与常见任务定位 | 当前迭代、跨分支上下文切换 |
| [board-code-map.md](board-code-map.md) | 自由画布链路、参数流和面板细节 | 修改自由画布功能 |
| [board-video-code-map.md](board-video-code-map.md) | 自由画布视频生成链路 | 修改视频生成、模型、图层或回填 |

## 使用顺序

1. 从当前需求、Spec 或路由确定业务入口。
2. 只读取对应地图及其直接链接的 Memory/Skill。
3. 用当前分支源码验证地图中的路径、符号和行为。
4. 地图与源码冲突时，以当前源码证据为准，并将地图标为待更新；不得静默沿用旧结论。

## 维护与同步

- 中枢 Code Map 只描述已审查的共享代码基线，不接收工程副本的自动覆盖。
- 分支新增或变化中的链路先留在 Feature 产物，稳定后再人工晋级。
- 不保存或分发数据库、缓存、日志和运行时文件。
- ABC 的具体同步操作只以 `E:\memory\SYNC.md` 为准。
